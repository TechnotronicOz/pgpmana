pgpass manager for Mac

Your ~/.pgpass, finally easy to read.

pgpmana shows each entry in your PostgreSQL password file as labeled fields: host, port, database, user and password, with no colons to count. It also points out lines that can never match, and when you save, it handles the escaping and keeps the file at mode 0600.

Features

It reads the file the way libpq does.

libpq uses the password from the first line that matches. A wildcard line near the top can hide more specific lines further down, and a text editor gives you no hint.

Finds entries that never match

When an earlier, broader line matches everything a line would, pgpmana marks the hidden line "never used". One click moves it above the line that hides it.

Fixes the order

One click moves each hidden entry directly above the entry that hides it. A preview lists every move first, and exact duplicates get their own "remove" button.

Tests the login

If psql is installed, pgpmana logs in with that one entry's password, so a password that was rotated and never updated shows up right away.

Match tester

Type a host, port, database and user. The tester shows the entry that supplies the password, the later matches libpq skips, and the field that rules out each other line.

Saves safely

pgpmana backs up the old file, then writes the new one with mode 0600 and swaps it in. ⌘Z undoes any change, and if another app edits the file, pgpmana reloads it.

Permission check

libpq ignores a password file that group or others can read. pgpmana warns you when that's the case and fixes it to 0600 in one click.

Paste a connection URL

Paste postgres://user:pass@host:5432/db and pgpmana fills in a new entry, with the escaping done for you.

Leaves the rest alone

Comments, blank lines and line order stay where you put them. pgpmana writes untouched lines back byte for byte.

Keyboard friendly

⌘K tests a connection, ⇧⌘C copies the password and ⌥⌘F fixes the order. Hover any icon in the action bar to see its shortcut.

How it works

Check a connection before psql does.

  1. Open your filepgpmana reads ~/.pgpass, or the file in $PGPASSFILE when you launch it from a shell that sets it.
  2. Spot and fix the problemspgpmana marks entries that an earlier wildcard hides, and Fix order moves them where they'll match. If the file's permissions are too open, a warning bar says so.
  3. Test a connectionThe match tester shows the winning entry and strikes through each field that doesn't match. Test connection then logs in with psql to prove the password still works.
  4. SavePress ⌘S. pgpmana keeps a backup and won't overwrite the file if something else changed it after you opened it.

Install

Build it from source.

pgpmana is a Swift package. Clone it, run the tests, and build the app bundle with one script.

# Get the code
$ git clone https://github.com/TechnotronicOz/pgpmana.git
$ cd pgpmana

# Optional: run the parser and matcher tests
$ swift test

# Build pgpmana.app and install it
$ ./scripts/bundle.sh
$ cp -R build/pgpmana.app ~/Applications/

Requirements

  • macOS 14 (Sonoma) or later
  • Xcode 15 or later. The Command Line Tools can build the app but can't run the tests.
  • Not sandboxed, so it can read and write ~/.pgpass directly
  • Optional: psql for connection tests. brew install libpq provides it. Everything else works without it.

Want to try it without touching your own file? From the repo, run chmod 600 Design/demo.pgpass, then PGPASSFILE="$PWD/Design/demo.pgpass" swift run pgpmana.

Stop counting colons.

pgpmana opens the hidden file and shows every entry as labeled fields, so you never have to work out which colon is which. It's free and open source.
